# AAU Dynasty — shared Drive reference index

This index is for the shared creative and documentation library. The Git repository remains the only canonical engineering source.

## Folders

- **Creative Assets:** approved or review-ready art references, card imagery, screenshots, and visual direction.
- **Project Documentation:** design decisions, gameplay notes, release checklists, and session handoffs.
- **Source Archives and Verification:** dated source snapshots, provenance records, screenshots, and test evidence.

## Current reference set

## Rules

- Treat the repository as the source of truth for code and generated outputs.
- Treat Drive as a shared reference library, not a second code repository.
- Keep credentials, private account data, internal machine paths, and hosting identifiers out of shared documents.
- Record the date and purpose when adding a new archive or creative reference.
